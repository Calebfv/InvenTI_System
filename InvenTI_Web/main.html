❓ Guía de Usuario

🎯 Bienvenido al Sistema InvenTI Web

Este sistema te permite gestionar el inventario de equipos informáticos de tu institución.

🟢 Estados de Equipos:

  • Verde (Operativo): Equipo funcionando correctamente
  • Amarillo (Atención): Requiere mantenimiento o actualización
  • Rojo (Inactivo): Fuera de servicio o averiado

📋 Cómo usar el sistema:

  1. Usa el Dashboard para ver un resumen general y gestionar laboratorios.
  2. Ve a "Equipos" para gestionar el inventario completo.
  3. Utiliza los filtros para encontrar equipos específicos.
  4. Haz clic en "Agregar Equipo" para registrar nuevos dispositivos.
  5. Registra mantenimientos en la sección "Mantenimiento".
  6. Consulta estadísticas y genera informes en "Reportes".
